# txpd

腾讯频道（pd.qq.com）插件：**聊天指令 + Web 管理面板 + 定时发帖**。

项目地址：<https://github.com/ElainaCore/elaina-plugin-Tencent_Channel>

Web 面板把腾讯频道的官方前端页面镜像到宿主里跑，登录、加入频道、发帖、评论、点赞、私信等操作全部由本机登录的
CLI 账号完成 —— 浏览器端不需要登录腾讯频道。

## 特性

- **聊天指令**：频道/帖子/成员查询与搜索、发帖与版块管理、成员管理（私信 / 禁言 / 踢出 / 设管理员）、
  加入与创建频道、多账号槽位切换（仅插件管理员可用，支持预演模式 `--dry-run`）。
- **Web 面板**：探索发现、频道主页、帖子详情、发帖、评论/回复、点赞、表情、私信列表、动态流；
  页面外观与原站一致，交互改由 CLI 账号驱动。
- **定时发帖**：Cron 计划（每天 / 每周 / 每 30 分钟 / 自定义），支持版块、标题、纯文本 / Markdown / HTML、图片。
- **通知**：新评论、新私信推送到群。
- **多账号**：每个账号槽位独立 HOME，登录态互不干扰。

## 安装

1. 把本目录（整个文件夹）放进宿主的插件目录，
   插件内部全部使用相对路径，不依赖目录名；宿主启动时自动加载，改动后支持热重载。
2. 插件市场自行安装

## 配置

| 项 | 位置 | 说明 |
|---|---|---|
| 插件管理员 | `admins.txt`（一行一个 ID）或面板「插件管理员」页 | 未配置时指令会提示；面板同样只对管理员开放 |
| 账号 | 面板左下角「登录 / 切换账号」扫码 | 可建多个槽位，每个槽位独立登录态 |
| 网页登录态（可选） | `web/pd-cookie.txt` 或 `users/<槽位>/pd-cookie.txt` | 放入 pd.qq.com 的网页 Cookie 后，页面按登录态渲染；不填则走「匿名浏览 + CLI 接管操作」 |

## Web 面板

在宿主「扩展页面」里打开**腾讯频道**即可，页面本身就是镜像的官方前端：

- **探索发现 / 频道主页 / 帖子详情**：与原站一致；未加入的频道、访客受限的频道都能正常看到内容（受限频道由
  服务端放开访客权限位并用 CLI 数据填充帖子列表，CLI 不可用时回退到插件自绘的同款布局）。
- **发帖**：点频道页的发帖框就地展开编辑器，支持标题、版块、Markdown、图片，以 CLI 当前账号身份发表。
- **评论 / 回复 / 点赞**：帖子详情底部输入栏即点即用，系统表情以表情图显示（提交时还原为平台节点语法）。
- **顶栏**：频道名右侧是「配置 / 定时 / 成员」图标按钮（与官方分享按钮同款）；下滑自动收起、回顶展开。
- **导航**：侧栏「动态」聚合已加入频道的帖子流；「私信列表」「插件管理」「定时发帖」为插件功能入口。

## 目录结构

```
main.py                      插件入口（指令 / 面板 / 定时器注册）
env_setup.py                 依赖自检：Linux/macOS 自动补全 CLI
requirements.txt             Python 依赖
commands/                    聊天指令层
  runtime.py                 平台与 CLI 调用、账号槽位、路径解析（核心）
  formatting.py              输出渲染与交互（卡片 / 表格 / 按钮）
  feeds.py  management.py  accounts.py  system.py  channel.py
services/
  scheduling.py              定时发帖调度
  notifications.py           评论 / 私信通知
web/
  panel.py                   面板后端：路由注册、CLI action 白名单、pd.qq.com 代理、页面挂载
  panel/index.html           镜像的官方页面
  panel/assets/              镜像的官方静态资源 + txpd-inject.js（站点适配脚本）
  panel/_feed_tpl.json       受限频道 feeds 响应的结构模板（无任何真实数据）
```

**`web/panel/assets/txpd-inject.js`** 是所有页面适配逻辑所在：`*.qq.com` 请求拦截与改写、登录/加入/评论/点赞/发帖
改走 CLI、镜像页路径对齐、以及详情浮层、表情面板、动态页等界面复刻。改页面行为从这里入手。
