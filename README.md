# txpd · 腾讯频道插件

支持聊天指令、Web 管理面板、定时发帖、评论与私信通知，以及多账号切换。

项目地址：<https://github.com/ElainaCore/elaina-plugin-Tencent_Channel>

## 安装与登录

1. 从宿主插件市场安装，或将整个项目文件夹放入宿主的插件目录后启动宿主。
2. 在 `data/admins.txt` 中填写管理员 openid，一行一个；也可在 Web 面板的「插件管理员」页配置。
3. 发送 `频道登录`，扫码授权后发送 `频道登录确认`。
4. 发送 `频道自检` 检查状态，发送 `频道帮助` 查看完整指令。

聊天指令仅限已配置的插件管理员使用。预演模式默认开启；需要实际执行写操作时，发送 `频道关闭预演`，可用 `频道开启预演` 恢复。

## 常用指令

- `频道列表`：查看已创建、管理或加入的频道。
- `频道版块 <频道ID>`：查看版块列表。
- `频道帖子 <频道ID>`：查看频道帖子。
- `帖子详情 <帖子ID>`：查看帖子详情。
- `频道发帖 <频道ID> <版块ID> <内容>`：发布普通帖子。
- `频道MD长帖 <频道ID> <版块ID> <标题> | <正文>`：发布 Markdown 长帖。
- `频道账号列表` / `频道切换账号 <名称>`：查看或切换账号。
- `频道登录状态`：查看当前账号的登录状态。

搜索、成员管理、评论回复及通知相关指令见 `频道帮助`。

## Web 面板

在宿主 Web 后台打开「腾讯频道」，可浏览频道、发帖、评论、点赞，并管理账号、定时发帖和通知。

面板直接使用本地 HTML、原有样式和插件自己的路由、交互代码，不启动腾讯官网的 Vue/Nuxt 应用。页面先显示，账号与内容在后台加载，接口延迟不会阻塞整个面板；刷新时可复用经过 ETag 校验的静态资源。

频道内容和操作使用当前 CLI 账号。管理页仍保留网页登录入口及其状态管理，操作账号需单独登录。升级后请重载插件，再刷新面板，以注册新的本地应用脚本。

## 数据备份

运行数据保存在 `data/`，包含配置、账号登录态、定时计划和发帖历史。迁移或备份时保留整个目录。
