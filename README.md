# txpd

腾讯频道（pd.qq.com）插件：**聊天指令 + Web 管理面板 + 定时发帖**。

项目地址：<https://github.com/ElainaCore/elaina-plugin-Tencent_Channel>

Web 面板把腾讯频道的官方前端页面镜像到宿主里跑，发帖、评论、点赞、加入频道、私信等**操作**全部由本机登录的 CLI 账号完成 —— 浏览器端不需要登录腾讯频道。面板里另有一套**网页扫码登录**（复刻官方登录），它只用来让页面按 登录态**显示**内容，不参与任何操作。

## 特性

- **聊天指令**：频道/帖子/成员查询与搜索、发帖与版块管理、成员管理（私信 / 禁言 / 踢出 / 设管理员）、 加入与创建频道、多账号槽位切换（仅插件管理员可用，支持预演模式 `--dry-run`）。
- **Web 面板**：探索发现、频道主页、帖子详情、发帖、评论/回复（含楼中楼）、点赞、表情、私信列表、动态流、插件管理页； 页面外观与原站一致，交互改由 CLI 账号驱动；另提供复刻官方的**网页扫码登录**（仅用于按登录态显示内容）。 频道主页完全由**官方前端自己渲染**（插件只在服务端把访客权限位与帖子数据补齐）， 手写复制官方骨架的兜底已删除——点进去就是官方页面，官方改版也不会让界面走样。
- **定时发帖**：Cron 计划（每天 / 每周 / 每 30 分钟 / 自定义），支持版块、标题、纯文本 / Markdown / HTML、图片。
- **通知**：新评论、新私信推送到群。
- **多账号**：每个账号槽位独立 HOME，登录态互不干扰。

## 安装

1. 把本目录（整个文件夹）放进宿主的插件目录， 插件内部全部使用相对路径，不依赖目录名；宿主启动时自动加载，改动后支持热重载。
2. 插件市场自行安装

## 聊天指令

> 命令均以「频道 / 帖子」开头，仅 `data/admins.txt` 中的管理员可用。发送 `频道帮助` 查看机器上的完整列表。

**核心**

| 命令 | 说明 |
|---|---|
| `频道帮助` | 完整帮助 |
| `频道自检` | 检查登录与插件状态 |
| `频道列表` | 我创建 / 管理 / 加入的频道 |
| `频道配置token <token>` | 配置或替换 token |
| `频道开启预演` / `频道关闭预演` | 预演模式（写操作只校验参数，不实际执行） |
| `频道开启调试` / `频道关闭调试` | 调试模式（回复附带原始 JSON） |

**查询与搜索**

| 命令 | 说明 |
|---|---|
| `频道资料 <频道ID>` / `频道版块 <频道ID>` / `频道成员 <频道ID>` / `频道帖子 <频道ID>` | 频道信息 / 版块 / 成员 / 帖子列表 |
| `频道用户资料 [频道ID 用户ID]` | 自己或指定用户资料 |
| `频道加入方式 <频道ID>` | 加入规则 |
| `频道搜帖 <频道ID> <关键词>` / `频道搜成员 <频道ID> <昵称>` | 频道内搜索 |
| `频道搜频道 <关键词>` / `频道搜作者 <关键词>` / `频道全局搜帖 <关键词>` | 全局搜索 |

## 目录结构

```
main.py                      插件入口（指令 / 面板 / 定时器注册）
env_setup.py                 依赖自检：Linux/macOS 自动补全 CLI
requirements.txt             Python 依赖
commands/                    聊天指令层
  runtime.py                 平台与 CLI 调用、账号槽位、路径解析（核心）
  formatting.py              输出渲染与交互（卡片 / 表格 / 按钮）
  feeds.py  management.py  accounts.py  system.py  channel.py
services/
  scheduling.py              定时发帖调度
  notifications.py           评论 / 私信通知
web/
  panel.py                   面板后端：路由注册、CLI action 白名单、pd.qq.com 代理、页面挂载
  panel/index.html           镜像的官方页面
  panel/assets/              镜像的官方静态资源 + txpd-inject.js（站点适配脚本）
  panel/_feed_tpl.json       受限频道 feeds 响应的结构模板（无任何真实数据）
data/                        运行期数据（不入库，备份/迁移只需搬这一个目录）
  admins.txt                 插件管理员（一行一个 openid）
  users.json                 账号槽位列表与昵称
  users/<槽位>/              槽位 HOME：.qqcli 登录态、token_store.json、pd-cookie.txt、登录二维码
  pd-cookie.txt              全局 pd.qq.com 网页 Cookie（可选）
  plugin_settings.json       预演 / 调试等开关
  feed_schedules.json        定时发帖计划
  post_history.json          发帖历史
  comment_notify_seen.json   评论通知去重（无槽位时的全局档）
  dm_notify_seen.json        私信通知去重（无槽位时的全局档）
  _joined_guilds.json        已加入频道缓存（首屏免等 CLI）
  uploads/                   面板发帖上传的图片
  .cli/                      Linux/macOS 缺 CLI 时 npm 本地安装的位置
  .home/                     Linux/macOS 无可用 HOME 时的回退 HOME
```

**`web/panel/assets/txpd-inject.js`** 是所有页面适配逻辑所在：`*.qq.com` 请求拦截与改写、登录/加入/评论/点赞/发帖 改走 CLI、镜像页路径对齐、以及详情浮层、表情面板、动态页等界面复刻。改页面行为从这里入手。
